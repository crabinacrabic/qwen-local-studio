# Qwen AI Studio (Local) 🚀

Локальный веб-интерфейс и диспетчер моделей для работы с открытыми нейросетями семейства **Qwen** (и DeepSeek) через **Ollama**.

## Особенности
- 💬 **Интерактивный веб-чат** с отображением цепочки рассуждений (`Thinking...`) в реальном времени.
- 🌐 **Живой выход в интернет (Web Search & Browsing)**: поиск актуальных данных в сети без платных ключей, чтение веб-страниц по прямым ссылкам и цитирование первоисточников.
- 📚 **Локальный RAG (База знаний)**: поиск по личным документам (.txt, .md, .json, .csv, .docx, код) через векторные эмбеддинги `nomic-embed-text` с цитированием источников и % совпадения.
- 📥 **Встроенный загрузчик и автообновление моделей**: автоматическое отслеживание новых поколений Qwen при запуске с возможностью безопасной замены старых версий (для экономии места).
- 🗑️ **Управление и удаление**: освобождение дискового пространства прямо из интерфейса.
- ⚡ **100% приватность**: генерация выполняется на локальном GPU (протестировано на AMD Radeon RX 6600 8GB VRAM).
- 📜 **Логирование**: автоматическая запись действий и ошибок в `app.log`.

## Быстрый запуск
1. Установите [Ollama](https://ollama.com/) и убедитесь, что служба запущена.
2. Запустите `start_web_chat.bat` (требуется Node.js).
3. Чат откроется в браузере по адресу `http://localhost:3000`.

## Автоматическое отслеживание новинок и обновление моделей
1. При запуске приложение само опрашивает официальную библиотеку Ollama.
2. Если для установленных у вас моделей появились новые поколения (например, `qwen3:8b` ➔ `qwen3.5:9b` или `qwen3-embedding`), приложение покажет модальное окно с выбором:
   - **Заменить**: скачать новую версию и безопасно удалить старую (освободив 5–10 ГБ на диске).
   - **Оставить обе**: скачать новую модель, сохранив текущую для сравнения.
   - **Пропустить**.
3. В любой момент можно нажать **«🔄 Проверить новые модели»** в панели `⚙️ Модели`.

## Живой интернет и Веб-поиск
1. Нажмите кнопку **«🌐 Интернет: ВКЛ»** в шапке чата (загорится голубым).
2. Задайте любой вопрос об актуальных событиях, курсах валют, свежем железе или новостях.
3. Модель в реальном времени выполнит поиск, глубоко прочитает релевантные веб-страницы и ответит со ссылками `[1]`, `[2]` на первоисточники.
4. *Совет: Вы также можете просто отправить ссылку на статью в чат — модель прочитает её содержимое и ответит на любые вопросы.*

## База знаний (RAG)
1. Нажмите кнопку **«📂 База знаний»** в шапке чата.
2. Перетащите файл (.docx, .txt, .md, код) или вставьте текст заметки и нажмите **«Индексировать текст»**.
3. Убедитесь, что кнопка **«📚 RAG: ВКЛ»** активна (зеленая).
4. Задайте любой вопрос по содержимому документов — модель ответит точно по вашим данным и покажет плашку с цитируемыми источниками.

> [!TIP]
> Кнопки **«🌐 Интернет»** и **«📚 RAG»** могут работать одновременно: модель будет отвечать, сопоставляя ваши личные материалы со свежими фактами из интернета!

## Поддерживаемые актуальные модели (2026)
- `qwen3.5:9b` (Новейший флагман: контекст 256K, мультимодальность, идеален для 8 GB VRAM)
- `qwen3.5:4b` (Сверхбыстрая модель нового поколения, 3.4 GB)
- `qwen3-vl:4b` (Мультимодальная модель со зрением для скриншотов и картинок)
- `qwen3-embedding:0.6b` (Официальные эмбеддинги Qwen для RAG с контекстом 32K)
- `qwen3.8:27b` (Тяжелая флагманская модель для offload в 16 GB RAM)
- `qwen3:8b` / `qwen3:4b` (Предыдущее классическое поколение Qwen3)
- `qwen2.5-coder:7b` / `qwen2.5-coder:14b` (Специализированные модели для программирования)
