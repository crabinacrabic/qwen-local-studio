# Qwen AI Studio (Local) 🚀

Локальный веб-интерфейс и диспетчер моделей для работы с открытыми нейросетями семейства **Qwen** (и DeepSeek) через **Ollama**.

## Особенности
- 💬 **Интерактивный веб-чат** с отображением цепочки рассуждений (`Thinking...`) в реальном времени.
- 📚 **Локальный RAG (База знаний)**: поиск по личным документам (.txt, .md, .json, .csv, код) через векторные эмбеддинги `nomic-embed-text` с цитированием источников и % совпадения.
- 📥 **Встроенный загрузчик моделей**: скачивание в один клик с цветным прогресс-баром и счетчиком мегабайт.
- 🗑️ **Управление и удаление**: освобождение дискового пространства прямо из интерфейса.
- ⚡ **100% оффлайн**: вся генерация и векторный поиск выполняются локально (протестировано на AMD Radeon RX 6600 8GB VRAM).
- 📜 **Логирование**: автоматическая запись действий и ошибок в `app.log`.

## Быстрый запуск
1. Установите [Ollama](https://ollama.com/) и убедитесь, что служба запущена.
2. Запустите `start_web_chat.bat` (требуется Node.js).
3. Чат откроется в браузере по адресу `http://localhost:3000`.

## База знаний (RAG)
1. Нажмите кнопку **«📂 База знаний»** в шапке чата.
2. Перетащите файл или вставьте текст заметки и нажмите **«Индексировать текст»**.
3. Убедитесь, что кнопка **«📚 RAG: ВКЛ»** активна (зеленая).
4. Задайте любой вопрос по содержимому документов — модель ответит точно по вашим данным и покажет плашку с цитируемыми источниками.

## Поддерживаемые модели
- `qwen3:8b` (Флагман, сбалансированное мышление)
- `qwen3:14b` (Глубокая логика и сложные рассуждения)
- `qwen2.5-coder:7b` / `qwen2.5-coder:14b` (Эталон для кодинга)
- `qwen3:4b` / `qwen3:1.7b` / `qwen3:0.6b` (Компактные модели)
- `nomic-embed-text` (Локальная модель векторных эмбеддингов для RAG)
