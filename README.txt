               ЛОКАЛЬНЫЙ ЧАТ С QWEN3 0.6B

Поздравляем! Модель Qwen3 0.6B установлена и работает
полностью локально на твоем компьютере с ускорением на видеокарте
AMD Radeon RX 6600 (8 GB VRAM).

КАК ЗАПУСТИТЬ:
--------------
1. Просто дважды кликни по файлу:
   "Запустить_Qwen3.bat"

2. Откроется окно терминала с приглашением к диалогу.

3. Напиши свой вопрос или попроси помочь с кодом.
   Например:
   - "Напиши базовую разметку HTML для страницы с карточкой профиля"
   - "Что делает тег <div> и чем он отличается от <span>?"
   - "Напиши CSS, чтобы расположить элементы по центру экрана"

КАК ВЫЙТИ:
----------
Напиши /bye или просто закрой окно терминала.
